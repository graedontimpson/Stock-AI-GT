# Product — Prompt

Read `00_context/project.md` and `00_context/glossary.md` first.

Define the first version of the Stock AI Analyzer as a product. Do not design
the architecture or write code; that comes in later stages.

Write the result to `01_product/output.md` with these sections:

1. **User** — who this is for and what they already know about stocks.
2. **Problem** — what the user is trying to find out or decide.
3. **Input** — what the user provides (for example a ticker symbol and a date range).
4. **Output** — what the user gets back, including what the Jev analysis
   contributes and how the result stays readable for a beginner.
5. **User flow** — the steps from opening the tool to reading the result.
6. **In scope for version 1** — the smallest set of features that is useful.
7. **Out of scope** — what is deliberately left for later.
8. **Open questions** — decisions that need a human answer before design continues.

Rules:

- Prefer the simplest version that works.
- Explain any finance or technical term a beginner might not know.
- The tool informs; it does not give financial advice. Say how the output makes that clear.
